# شركة إنجاز للمقاولات والتوريدات ونقل البضائع
### Enjaz for Contracting, General Supplies & Domestic Freight Transport

الموقع التعريفي الرسمي لشركة إنجاز (سجل تجاري رقم 130907).

---

## مجالات عمل الشركة الرئيسية:
1. **المقاولات العامة وتجهيز المواقع**: تنفيذ أعمال المقاولات، تجهيز المواقع الإنشائية، والمكاتب الميدانية المؤقتة.
2. **التوريدات العمومية وخامات التشغيل**: توريد مستلزمات التشغيل، مواد التعبئة والتغليف، الكراتين، ومهمات السلامة المهنية (PPE).
3. **نقل البضائع والشحن البري**: شبكة شحن بري مباشر تربط القاهرة بـ 27 محافظة من الباب للباب دون تفريغ وسيط.
